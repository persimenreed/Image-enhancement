# Image-enhancement
In this project, different super-resolution techniques are implemented to enhance images. All methods are evaluated using both PSNR and SSIM evaluation metrics.

The following image enhancement techniques are implemented:
  - Nearest Neighbour Interpolation
  - Bilinear Interpolation
  - Bicubic Interpolation
  - New Edge Directed Interpolation
  - Super-Resolution Convolutional Neural Network
